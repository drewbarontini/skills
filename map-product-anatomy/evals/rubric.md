# Evaluation Rubric

Score the six core dimensions from 0 to 2. Score Breadboard fidelity and Reconciliation only when that continuation is requested or returned artifacts need review.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Notation fidelity | Invalid or invented notation obscures the anatomy | Mostly valid Anatomica with minor inconsistencies | Uses Anatomica correctly and consistently |
| Structural fidelity | Confuses Screens, Components, States, or Actions | Most concepts are correctly classified, with some unclear ownership | Places each concept at the correct and narrowest useful structural level |
| Flow clarity | Omits or obscures meaningful transitions | Shows some transitions but leaves supported movement implicit | Makes supported transitions visible and understandable |
| Naming consistency | Repeated concepts use conflicting names | Names are mostly stable with minor drift | Uses consistent names for repeated product concepts and behaviors |
| Epistemic restraint | Invents unsupported behavior or presents assumptions as fact | Preserves some uncertainty but fills minor gaps | Maps only supported evidence and makes assumptions and Unknowns explicit |
| Compression | Verbose or fragmented enough to resist inspection | Understandable but contains avoidable repetition | Compact and diffable without losing meaningful structure |
| Breadboard fidelity (conditional) | Drawing changes identities, invents routes, or falsely claims rendering | Mostly faithful, with unclear ownership, action labels, or scope seams | Legible places and affordances, correct action origins and destinations, distinct annotations, preserved state-view and shared-context identity, visible Unknowns, and inspected rendering when available |
| Reconciliation (conditional) | Changes one artifact while others contradict it, or treats sketches as validation | Notices drift without resolving artifact relationships | Distinguishes rendering errors from proposed decisions and keeps accepted changes aligned across pitch, anatomy, and drawing |

**10–12:** clear, faithful, useful product anatomy. **7–9:** useful representation with structural or notation weaknesses. **0–6:** speculative specification, implementation map, or inconsistent notation rather than Product Anatomy.

For applicable conditional dimensions, a score of 2 indicates a useful continuation; 1 needs refinement; 0 exposes a material failure even if the core text score is strong. A text-only request is not penalized for having no drawing.
