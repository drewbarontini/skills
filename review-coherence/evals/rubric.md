# Evaluation Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Evidence | Taste or speculation only | Some artifact evidence | Specific evidence plus explicit context limits |
| Comparative rule | No baseline | Implied convention | Clear internal, neighboring, or user-model comparison |
| Mental model | Ignores interpretation | Mentions confusion | Traces expectation, product model, and mismatch source |
| Whole-product view | Reviews local polish only | Notes one seam | Finds contradictions, duplication, or drift across the system |
| Consequence | Says “inconsistent” only | Generic usability concern | Explains interpretive, behavioral, or systemic harm |
| Correction | Unbounded redesign | Plausible fix | Smallest correction that restores or clarifies the rule |

**10–12:** grounded, systemic, and actionable. **7–9:** useful findings with weak evidence or prioritization. **0–6:** aesthetic critique or inconsistency list without a coherence model.
