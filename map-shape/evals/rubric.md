# Evaluation Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Method fidelity | Omits or reorders core method without reason | Uses all steps superficially | Surface → Structure → Slice → Simplify → Sequence changes the shape |
| Visibility and structure | Hides unknowns or lists tasks only | Shows some groups | Tags mixed inputs and maps roots, nesting, and dependencies |
| Slice value | Horizontal layers or arbitrary phases | Partly usable capabilities | Small, complete, independently testable user-value flows |
| Simplification | No real subtraction | Defers incidental scope | Reduces each slice while preserving essential value |
| Sequence | Implementation chronology only | Dependency-aware | Distinguishes build units, value units, and bundles |
| Epistemic restraint | Invents requirements | Marks some assumptions | Preserves Decisions, Questions, Risks, and Unknowns |

**10–12:** coherent and ready to guide product work. **7–9:** useful shape with weak slices or subtraction. **0–6:** task breakdown or speculative specification, not Shape Mapping.
