# Evaluation Rubric

Score each dimension from 0 to 2. Evaluate the behavior appropriate to the available context and interview stage, not exact wording or whether every turn includes a complete pitch.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Interview judgment | Fixed questionnaire, repeated questions, or invented answers | Useful questions with weak prioritization | Focused questions that change the shape, appropriate waiting, and direct synthesis when context suffices |
| Method fidelity | Task breakdown replaces shaping | Five steps applied superficially | Surface → Structure → Slice → Simplify → Sequence materially improves the shape |
| Pitch usefulness | Speculative specification or wrong default artifact | Understandable but bloated or weakly bounded | Concise Problem / Solution / Scopes pitch with uncertainty kept where it matters; requested detailed map respected |
| User value and relationships | Technical layers or arbitrary screen lists | Some meaningful flows | Bounded user-facing outcomes with dependencies and value bundles made explicit |
| Simplification and fit | Adds ungrounded concepts or never subtracts | Defers incidental scope | Narrows scope while preserving value and reusing the existing product's concepts |
| Epistemic restraint | Suggestions, sketches, or assumptions become facts | Some uncertainty marked | Evidence, assumptions, proposals, decisions, and unresolved risks remain distinguishable |
| Readiness and next action | Endless interview or false production certainty | Suggests a next action without explaining readiness | Distinguishes sketch from prototype readiness and directs each consequential unknown to a useful next action |
| Artifact continuity | Restarts or creates a disconnected specification | Mentions returned artifacts | Traces sketches/prototypes against the existing pitch, resolves meaningful contradictions, and revises the same artifact |

**13–16:** coherent shaping appropriate to the current stage. **9–12:** useful but weak on interviewing, boundaries, or next action. **0–8:** questionnaire, task breakdown, or speculative specification.
