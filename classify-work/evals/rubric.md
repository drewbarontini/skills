# Evaluation Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Type | Invents or conflates category | Plausible with weak rationale | Exactly one established Type based on current intent |
| Impact | Invented score or priority | Generic consequence | Evidence-based affected party, consequence, and uncertainty |
| Landscape | Fabricated hierarchy | Maps only broad supplied area | Uses existing Region → Zone → Context at supported depth |
| Form | Confuses item Type and container | Plausible but underexplained | Correctly distinguishes Standalone, Batch, Stream, and Project |
| Route | Claims unsupported status | Valid lane with weak commitment logic | Lane reflects current state and increasing commitment |
| Evolution | Treats classification as permanent | Notes ambiguity | Explains alternatives, missing context, and reclassification triggers |

**10–12:** compact, legible coordinates. **7–9:** usable with one uncertain axis. **0–6:** invented taxonomy or conflated type, impact, form, and status.
