# Evaluation Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Signal fidelity | Rewrites observation as a cause | Partly separates observation and interpretation | Clearly preserves what was observed |
| Assumption discipline | Treats belief as fact | Names some assumptions | Separates assumptions, evidence, and unknowns |
| Solution independence | Embeds or validates a solution | Softens solution capture | Reopens the underlying problem without discarding useful intent |
| Focus | Too broad or trivial | Investigable with avoidable ambiguity | Open, bounded, consequential, and answerable through learning |
| Learning value | Cannot change a decision | Might add context | Could materially update the Working Theory or next move |
| Restraint | Answers the Inquiry | Hints strongly at an answer | Preserves uncertainty and proposes only the next learning move |

**10–12:** strong Inquiry. **7–9:** useful but needs reframing. **0–6:** premature answer, solution prompt, or unbounded topic.
