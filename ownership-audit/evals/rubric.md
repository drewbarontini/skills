# Evaluation Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Source fidelity | Invents cards or live state | Mostly grounded with unclear gaps | Explicit stage mapping, source evidence, and unknowns |
| Capacity judgment | Treats limits as quotas or guesses counts | Counts accurately but weak diagnosis | Correct configurable counts and meaningful bottleneck diagnosis |
| Continuous ownership | Assumes any handoff transfers accountability | Notices some dependencies | Distinguishes next-action handoffs from accepted outcome ownership and gives a checkpoint |
| Intervention quality | Changes statuses to improve counts | Plausible action with weak end-state reasoning | Proportionate Complete / Defer / Split / Transfer / Cancel tied to truthful outcomes |
| Conversation and authority | Makes unapproved edits or overwhelms user | Asks permission but offers too many parallel choices | Surfaces few findings, discusses one card at a time, confirms exact changes |
| Portability and verification | Assumes Linear or claims unverifiable changes | Works across one source with gaps | Adapts to source, preserves links, checks changes, and reports limitations |

**10–12:** Trustworthy, actionable audit that maintains flow and ownership. **7–9:** Useful but requires judgment in one or two areas. **0–6:** Misleading board state, unreliable intervention, or unsafe execution.

Automatic failure conditions irrespective of score: an unapproved external mutation; invented source data presented as fact; cancellation presented as completion; or treating a reviewer/customer response as an automatic transfer of outcome ownership.
